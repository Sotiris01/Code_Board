## 🔤 Τύποι Δεδομένων

| Τύπος | Δήλωση | Παράδειγμα |
|-------|--------|------------|
| Ακέραιος | `ΑΚΕΡΑΙΕΣ:` | `-1234567890`, `42` |
| Πραγματικός | `ΠΡΑΓΜΑΤΙΚΕΣ:` | `3.14`, `-0.5` |
| Χαρακτήρες | `ΧΑΡΑΚΤΗΡΕΣ:` | `'Μυρτώ'`, `"Ν"` |
| Λογικός | `ΛΟΓΙΚΕΣ:` | `ΑΛΗΘΗΣ`, `ΨΕΥΔΗΣ` |

**Σημειώσεις:**
- Οι λογικές μεταβλητές **δεν** μπορούν να διαβαστούν με `ΔΙΑΒΑΣΕ`
- Ανάθεση ακέραιου σε πραγματικό επιτρέπεται
- Ανάθεση πραγματικού σε ακέραιο **ΔΕΝ** επιτρέπεται

## ⚙️ Τελεστές

### Αριθμητικοί Τελεστές

| Τελεστής | Λειτουργία | Σημείωση |
|----------|------------|----------|
| `+` | Πρόσθεση | Ακέραιοι, Πραγματικοί |
| `-` | Αφαίρεση | Ακέραιοι, Πραγματικοί |
| `*` | Πολλαπλασιασμός | Ακέραιοι, Πραγματικοί |
| `/` | Διαίρεση | Αποτέλεσμα **πάντα** πραγματικός |
| `^` | Δύναμη | |
| `DIV` | Ακέραια διαίρεση | **Μόνο** ακέραιοι |
| `MOD` | Υπόλοιπο | **Μόνο** ακέραιοι |

> ⚠️ **ΜΗΝ** χρησιμοποιείτε `DIV` και `MOD` με αρνητικούς αριθμούς σε ασκήσεις!

### Συγκριτικοί Τελεστές

| Τελεστής | Σημασία |
|----------|---------|
| `<` | Μικρότερο |

| `=` | Ίσον |

| `>` | Μεγαλύτερο |
| `>=` ή `≥` | Μεγαλύτερο ή ίσο |

### Λογικοί Τελεστές

| Τελεστής | Σημασία |
|----------|---------|
| `ΚΑΙ` | AND - Αληθής αν **και οι δύο** αληθείς |

| `ΟΧΙ` | NOT - Αντιστροφή |

## 📝 Δομή Προγράμματος

```
ΠΡΟΓΡΑΜΜΑ ΌνομαΠρογράμματος
! Σχόλιο με θαυμαστικό

ΣΤΑΘΕΡΕΣ
  Π = 3.14

ΜΕΤΑΒΛΗΤΕΣ
  ΑΚΕΡΑΙΕΣ: x, y, z
  ΠΡΑΓΜΑΤΙΚΕΣ: a, b
  ΧΑΡΑΚΤΗΡΕΣ: name
  ΛΟΓΙΚΕΣ: flag

ΑΡΧΗ
  ! Εντολές εδώ
ΤΕΛΟΣ_ΠΡΟΓΡΑΜΜΑΤΟΣ
```

**Κανόνες ονομάτων:**
- Ξεκινούν με **γράμμα** (ελληνικό ή αγγλικό)
- Περιέχουν γράμματα, αριθμούς, ή `_`
- ❌ Λάθος: `1var`, `αρ-μαθητών`, `my var`
- ✅ Σωστό: `Μεταβλητή1`, `x`, `Αρ_Μαθητών`

## 📥📤 Είσοδος/Έξοδος

### ΔΙΑΒΑΣΕ (Είσοδος)
```
ΔΙΑΒΑΣΕ μεταβλητή1, μεταβλητή2
```
- Κάθε τιμή σε **ξεχωριστή γραμμή** (με Enter)
- **ΔΕΝ** διαβάζουμε λογικές μεταβλητές

### ΓΡΑΨΕ (Έξοδος)
```
ΓΡΑΨΕ 'Μήνυμα: ', μεταβλητή
ΓΡΑΨΕ        ! Αλλαγή γραμμής
```
- Με κενό στο τέλος → δρομέας στην **ίδια** γραμμή
- Χωρίς κενό → δρομέας στην **επόμενη** γραμμή

## 🔀 Δομές Επιλογής

### ΑΝ...ΤΟΤΕ...ΑΛΛΙΩΣ
```
ΑΝ συνθήκη ΤΟΤΕ
  εντολές
ΑΛΛΙΩΣ_ΑΝ συνθήκη2 ΤΟΤΕ
  εντολές
ΑΛΛΙΩΣ
  εντολές
ΤΕΛΟΣ_ΑΝ
```

> ⚠️ `ΑΛΛΙΩΣ_ΑΝ` ≠ `ΑΛΛΙΩΣ ΑΝ` (η δεύτερη είναι 2 εντολές!)

### ΕΠΙΛΕΞΕ
```
ΕΠΙΛΕΞΕ μεταβλητή
  ΠΕΡΙΠΤΩΣΗ τιμή1
    εντολές
  ΠΕΡΙΠΤΩΣΗ τιμή2, τιμή3..τιμή4
    εντολές
  ΠΕΡΙΠΤΩΣΗ > 100
    εντολές
  ΠΕΡΙΠΤΩΣΗ ΑΛΛΙΩΣ
    εντολές
ΤΕΛΟΣ_ΕΠΙΛΟΓΩΝ
```

## 🔁 Δομές Επανάληψης

### ΓΙΑ (Γνωστός αριθμός επαναλήψεων)
```
ΓΙΑ i ΑΠΟ 1 ΜΕΧΡΙ 10
  εντολές
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ

ΓΙΑ i ΑΠΟ 10 ΜΕΧΡΙ 1 ΜΕ_ΒΗΜΑ -1
  εντολές
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```

### ΟΣΟ (Έλεγχος στην αρχή)
```
ΟΣΟ συνθήκη ΕΠΑΝΑΛΑΒΕ
  εντολές
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```
- Μπορεί να μην εκτελεστεί **ποτέ**

### ΑΡΧΗ_ΕΠΑΝΑΛΗΨΗΣ...ΜΕΧΡΙΣ_ΟΤΟΥ (Έλεγχος στο τέλος)
```
ΑΡΧΗ_ΕΠΑΝΑΛΗΨΗΣ
  εντολές
ΜΕΧΡΙΣ_ΟΤΟΥ συνθήκη
```
- Εκτελείται **τουλάχιστον μία** φορά
- Σταματά όταν η συνθήκη γίνει **ΑΛΗΘΗΣ**

## 📌 Πρότυπα Αλγορίθμων (Exam Patterns)

### 1. Εύρεση Μεγίστου/Ελαχίστου σε Πίνακα
```
max <- Α[1]
θέση <- 1
ΓΙΑ i ΑΠΟ 2 ΜΕΧΡΙ Ν
  ΑΝ Α[i] > max ΤΟΤΕ
    max <- Α[i]
    θέση <- i
  ΤΕΛΟΣ_ΑΝ
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```

### 2. Σειριακή Αναζήτηση
```
found <- ΨΕΥΔΗΣ
i <- 1
ΟΣΟ i <= Ν ΚΑΙ found = ΨΕΥΔΗΣ ΕΠΑΝΑΛΑΒΕ
  ΑΝ Α[i] = key ΤΟΤΕ
    θέση <- i
    found <- ΑΛΗΘΗΣ
  ΤΕΛΟΣ_ΑΝ
  i <- i + 1
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```

### 3. Ταξινόμηση Φυσαλίδας (Bubble Sort)
```
ΓΙΑ i ΑΠΟ 2 ΜΕΧΡΙ Ν
  ΓΙΑ j ΑΠΟ Ν ΜΕΧΡΙ i ΜΕ_ΒΗΜΑ -1
    ΑΝ Α[j-1] > Α[j] ΤΟΤΕ
      ! Αντιμετάθεση
      temp <- Α[j-1]
      Α[j-1] <- Α[j]
      Α[j] <- temp
    ΤΕΛΟΣ_ΑΝ
  ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```

### 4. Άθροισμα/Μέσος Όρος
```
sum <- 0
ΓΙΑ i ΑΠΟ 1 ΜΕΧΡΙ Ν
  sum <- sum + Α[i]
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
μέσος_όρος <- sum / Ν
```

### 5. Καταμέτρηση με Συνθήκη
```
πλήθος <- 0
ΓΙΑ i ΑΠΟ 1 ΜΕΧΡΙ Ν
  ΑΝ Α[i] > 10 ΤΟΤΕ
    πλήθος <- πλήθος + 1
  ΤΕΛΟΣ_ΑΝ
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```

### 6. Μέγιστος Κοινός Διαιρέτης (Ευκλείδης)
```
ΟΣΟ β <> 0 ΕΠΑΝΑΛΑΒΕ
  υπόλοιπο <- α MOD β
  α <- β
  β <- υπόλοιπο
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
ΜΚΔ <- α
```

### 7. Παραγοντικό (n!)
```
factorial <- 1
ΓΙΑ i ΑΠΟ 1 ΜΕΧΡΙ n
  factorial <- factorial * i
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```

### 8. Έλεγχος Πρώτου Αριθμού
```
is_prime <- ΑΛΗΘΗΣ
i <- 2
ΟΣΟ i <= Τ_Ρ(n) ΚΑΙ is_prime = ΑΛΗΘΗΣ ΕΠΑΝΑΛΑΒΕ
  ΑΝ n MOD i = 0 ΤΟΤΕ
    is_prime <- ΨΕΥΔΗΣ
  ΤΕΛΟΣ_ΑΝ
  i <- i + 1
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```

### 9. Fibonacci
```
f1 <- 0
f2 <- 1
ΓΙΑ i ΑΠΟ 3 ΜΕΧΡΙ n
  f_new <- f1 + f2
  f1 <- f2
  f2 <- f_new
ΤΕΛΟΣ_ΕΠΑΝΑΛΗΨΗΣ
```

### 10. Επικύρωση Εισόδου (Input Validation)
```
ΑΡΧΗ_ΕΠΑΝΑΛΗΨΗΣ
  ΓΡΑΨΕ 'Δώσε αριθμό 1-10: '
  ΔΙΑΒΑΣΕ x
ΜΕΧΡΙΣ_ΟΤΟΥ x >= 1 ΚΑΙ x <= 10
```
